# Testing (Jest)

This package uses **Jest** for unit tests.

## Commands

From this package directory:

```bash
npm test
```

Watch mode:

```bash
npm run test:watch
```

Coverage:

```bash
npm run test:coverage
```

## Coverage output

Coverage artifacts are written to:

- `./coverage/lcov-report/index.html` (HTML report)
- `./coverage/lcov.info` (LCOV)
